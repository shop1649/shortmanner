volcano (개인 콘텐츠 업로드 도구) · 최종 갱신 2026-09-26

1. 서비스의 성격

volcano 는 운영자 본인이 만든 영상·이미지를 본인이 소유한 소셜 미디어 계정(TikTok, Instagram 등)에 올리기 위해 사용하는 개인용 도구입니다. 일반에 공개된 서비스가 아니며, 제3자에게 계정 접근 권한을 제공하거나 대행 게시를 판매하지 않습니다.

2. 이용 범위

  • 이 도구는 운영자 본인의 계정에만 연결됩니다.
  • 업로드되는 콘텐츠는 운영자가 직접 제작했거나 사용 권한을 확보한 것입니다.
  • 각 플랫폼(TikTok 등)의 커뮤니티 가이드라인과 이용약관을 따릅니다.

3. 금지되는 사용

  • 타인의 계정에 무단으로 게시하는 행위
  • 권리를 갖지 않은 콘텐츠의 업로드
  • 스팸, 자동 대량 발송, 플랫폼 정책을 우회하려는 행위

4. 연동 해제

연결된 계정은 각 플랫폼의 설정에서 언제든지 연동을 해제할 수 있습니다. 해제 즉시 이 도구는 해당 계정에 접근할 수 없습니다.

5. 책임의 한계

이 도구는 있는 그대로 제공되며, 플랫폼 API 의 변경·장애로 인한 업로드 실패에 대해 보증하지 않습니다. 게시된 콘텐츠에 대한 책임은 운영자 본인에게 있습니다.
